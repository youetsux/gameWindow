# 静的FBXの描画 · テクスチャ編

[形状編](../README.md)で作ったマテリアル別の描画範囲に、Diffuse画像を結び付けます。教材の `textured_cube.fbx` と `checkerboard_diffuse.png` を同じフォルダーに置き、Debug / x64 で実行します。立方体にチェック柄と「DIFFUSE」の文字が表示されます。

## 工程9 · Diffuse画像とUVを使う

1. `material->fbx.diffuse_color.texture` から画像参照を取得します。参照からファイル名を取り出し、FBXの親フォルダーと結合します。
2. 各面の角に対応するUVを取得します。画像の原点に合わせて、ゲームへ渡す値を `(u, 1 - v)` にします。
3. `Texture` で画像を読み込み、描画範囲ごとにシェーダーへ渡します。`Simple3D.hlsl` は、画像ありなら **Diffuse色 × 頂点カラー × 画像の色**、画像なしなら **Diffuse色 × 頂点カラー** を返します。

画像が未割り当ての場合、UVがない場合、画像を読めなかった場合も、色で描画できます。画像の読み込みに失敗したときは、Visual Studioの出力ウィンドウに解決後のファイルパスが出ます。

左手系への変換やFBX内の負のスケールで面の向きが反転する場合は、三角形の頂点順を反転して外側を描きます。UVと頂点カラーは面の角に対応したままです。

## 画面で確認する

- 同梱の立方体を表示し、回転に合わせてチェック柄が各面に付いてくることを確認します。
- FBXを別のフォルダーにコピーして画像を置かず、そのコピーを読み込むと、同じ形状が画像なしで表示されます。
- 二つのマテリアルを持つモデルでは、一方だけにDiffuse画像を割り当てると、画像ありと色のみの面が同時に表示されます。

同梱の残り5枚は発光・環境色・鏡面反射・透明度・反射チャンネルの参照画像です。この工程でサンプリングするのはDiffuse画像です。
